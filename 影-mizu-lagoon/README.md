# 影 Mizu Lagoon

Shallow lagoon teal, glass and salt air

Installed as `影-mizu-lagoon`, shown in the theme menu as **影 Mizu Lagoon**.
Apply it with `omarchy-theme-set 影-mizu-lagoon`.

A dark theme built around hue 176°, with 18 anime wallpapers picked because
their dominant colour already sat near that hue, then graded so each one's black
point matches `background`.
