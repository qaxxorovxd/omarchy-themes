# 影 Matcha Yuki

Matcha green resting under quiet snow

Installed as `影-matcha-yuki`, shown in the theme menu as **影 Matcha Yuki**.
Apply it with `omarchy-theme-set 影-matcha-yuki`.

A dark theme built around hue 104°, with 18 anime wallpapers picked because
their dominant colour already sat near that hue, then graded so each one's black
point matches `background`.
