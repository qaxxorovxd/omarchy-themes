# 影 Komorebi Gold

Sunlight leaking through summer leaves

Installed as `影-komorebi-gold`, shown in the theme menu as **影 Komorebi Gold**.
Apply it with `omarchy-theme-set 影-komorebi-gold`.

A dark theme built around hue 47°, with 18 anime wallpapers picked because
their dominant colour already sat near that hue, then graded so each one's black
point matches `background`.
