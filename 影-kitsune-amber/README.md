# 影 Kitsune Amber

Fox-fire amber on scorched charcoal

Installed as `影-kitsune-amber`, shown in the theme menu as **影 Kitsune Amber**.
Apply it with `omarchy-theme-set 影-kitsune-amber`.

A dark theme built around hue 27°, with 18 anime wallpapers picked because
their dominant colour already sat near that hue, then graded so each one's black
point matches `background`.
