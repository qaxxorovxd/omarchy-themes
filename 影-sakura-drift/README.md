# 影 Sakura Drift

Petal-soft rose over deep plum night

Installed as `影-sakura-drift`, shown in the theme menu as **影 Sakura Drift**.
Apply it with `omarchy-theme-set 影-sakura-drift`.

A dark theme built around hue 337°, with 18 anime wallpapers picked because
their dominant colour already sat near that hue, then graded so each one's black
point matches `background`.
