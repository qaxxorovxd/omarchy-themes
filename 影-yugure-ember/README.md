# 影 Yugure Ember

Dusk crimson, warm ash and ember glow

Installed as `影-yugure-ember`, shown in the theme menu as **影 Yugure Ember**.
Apply it with `omarchy-theme-set 影-yugure-ember`.

A dark theme built around hue 4°, with 18 anime wallpapers picked because
their dominant colour already sat near that hue, then graded so each one's black
point matches `background`.
