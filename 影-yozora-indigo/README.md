# 影 Yozora Indigo

Night-sky indigo with starlight blue

Installed as `影-yozora-indigo`, shown in the theme menu as **影 Yozora Indigo**.
Apply it with `omarchy-theme-set 影-yozora-indigo`.

A dark theme built around hue 217°, with 18 anime wallpapers picked because
their dominant colour already sat near that hue, then graded so each one's black
point matches `background`.
