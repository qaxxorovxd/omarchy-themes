# 影 Akihabara Neon

Arcade magenta burning through the rain

Installed as `影-akihabara-neon`, shown in the theme menu as **影 Akihabara Neon**.
Apply it with `omarchy-theme-set 影-akihabara-neon`.

A dark theme built around hue 303°, with 18 anime wallpapers picked because
their dominant colour already sat near that hue, then graded so each one's black
point matches `background`.
