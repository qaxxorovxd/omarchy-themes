# 影 Fuji Lavender

Wisteria lavender drifting over dusk

Installed as `影-fuji-lavender`, shown in the theme menu as **影 Fuji Lavender**.
Apply it with `omarchy-theme-set 影-fuji-lavender`.

A dark theme built around hue 263°, with 18 anime wallpapers picked because
their dominant colour already sat near that hue, then graded so each one's black
point matches `background`.
